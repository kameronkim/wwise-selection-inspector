# Wwise Selection Inspector

A lightweight standalone tool for inspecting selected objects in Wwise.

## Features

- Shows the current Wwise selection count
- Displays basic information about selected objects
- Runs as a small standalone window
- Provides a simple helper workflow for Wwise object inspection

## Usage

Launch the tool, then select one or more objects in Wwise.

The window updates based on the current selection.

## Requirements

- Wwise
- WAAPI enabled in Wwise
- Python runtime or bundled executable, depending on the distribution format
